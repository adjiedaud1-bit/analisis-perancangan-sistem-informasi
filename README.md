# Information System Analysis and Design

**Academic Project Portfolio | Muhammad Adjie Daud**

## Project Overview

This repository documents academic work and learning activities related to information system analysis and design. It focuses on understanding business requirements, identifying user needs, modeling system processes, and preparing structured system documentation.

The purpose of this portfolio is to demonstrate a systematic approach to analyzing problems and planning information systems.

## Objectives

- Identify business problems and user requirements.
- Document functional and non-functional requirements.
- Model system processes and interactions.
- Design database structures and relationships.
- Prepare clear and structured technical documentation.

## Project Scope

### 1. Requirements Analysis
Identify stakeholders, business needs, system objectives, and user requirements.

### 2. System Modeling
Prepare relevant UML diagrams, use case diagrams, and process models to describe system behavior.

### 3. Database Design
Develop Entity Relationship Diagrams (ERD) and define entities, attributes, primary keys, foreign keys, and relationships.

### 4. System Documentation
Organize the Software Requirements Specification (SRS), design decisions, and supporting project documentation.

## Tools and Technologies

Tools will be documented according to their actual use in the project, including diagramming applications, Microsoft Office, and other relevant software.

## Project Deliverables

The repository will contain the following materials as they are completed:

- Project overview and problem statement.
- System requirements documentation.
- Use case and UML diagrams.
- Entity Relationship Diagram (ERD).
- Interface design and screenshots, where available.
- Project conclusions and lessons learned.

## Project Status

**Status:** Documentation and portfolio development in progress.

This repository is intended to present academic work and verified project materials. Deliverables will be added as they are completed and reviewed.
